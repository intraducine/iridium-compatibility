Iridium Compatibility

Privacy

Anonymous browser identity

Your browser creates a random identifier in local storage. The server converts it to a keyed one-way hash before storing votes or compatibility ratings. The raw browser identifier is not stored in the database.

Compatibility reports

Compatibility ratings are scoped to the Iridium version they were submitted for. The current version is detected automatically, so older reports never affect the current compatibility score. A report can include optional notes. Ratings, versions, notes, and report dates may be shown publicly, but the identity behind a report is never shown.

What is not stored with public activity

The application does not store your name, email address, Steam account, GitHub account, or raw IP address with votes or compatibility ratings. Cloudflare may process network information to deliver and protect the service, but the application database does not save raw IP addresses.

Abuse protection

Cloudflare Turnstile and rate limiting protect searches, requests, votes, and ratings from automated abuse. Short-lived quota counters use anonymous keyed hashes.

Administration

GitHub authentication is used only for authorized administrators. The application verifies the allowed GitHub account and then issues a short-lived secure admin session. The admin session does not contain the GitHub username.
